# 资源管理

支持国服官服和 B 服。操作前请确认游戏目录与所选渠道一致。

## 安装和更新

已有游戏时，在“启动器”选择主程序；首次安装时，在“资源管理”选择新安装目录。

1. 选择渠道，点击“检查更新”。
2. 核对本地版本、官方版本、下载量和目标目录。
3. 点击“下载并更新”，等待完成。

助手会先下载并校验文件，再替换游戏资源。游戏运行期间无法安装更新；安装期间也无法从助手启动游戏。

下载设置支持并发数和总限速，限速为 0 时不限速。下载进度会显示当前文件、已处理文件数和字节数。

## 取消与继续下载

点击“取消更新”后，等待任务结束。已下载内容保存在游戏目录的 `.wwt-download-cache/`，下次检查并更新时可复用。

连接或程序意外中断后，重新打开助手并检查更新。助手会处理未完成的替换，再重新生成计划。恢复尚未完成时，请保留 `.wwt-transaction-*` 目录中的备份和记录。

## 校验和修复

在“更多工具”中点击“校验本地资源”。助手按官方清单检查文件，为缺失或损坏的内容生成修复计划。核对后开始修复。

游戏主程序丢失时，也可以通过已保存的安装路径检查和修复。差分更新所需的旧文件不可用时，助手会下载对应完整文件。

## 预下载

选择“下一版本预下载”，检查后开始下载。预下载期间可以继续运行当前游戏。

正式更新开放后，切回当前版本更新并重新检查，助手会复用已校验的预下载缓存。

## 官服与 B 服切换

在“服务器文件切换”中检查当前渠道，准备目标渠道缓存后再切换。缓存会保留，便于再次切回；页面显示缓存是否就绪及对应版本。

切换和修复前请退出游戏。游戏运行、资源安装或渠道切换进行期间，冲突操作会暂时禁用。

## 遇到问题

- 下载失败：确认网络与可用空间，重新检查后继续。
- 文件校验失败：再次执行校验并修复。
- 提示恢复失败：保留提示中的备份目录和运行日志，在本仓库反馈。
- 提示 HPatchZ 组件校验失败：重新解压完整便携包，保留原来的 `data/`。
