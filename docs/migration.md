# 原版数据导入

本页所说的原版助手是 [Leck / WutheringWavesTool](https://github.com/leck995/WutheringWavesTool)。导入支持国服数据。

打开“数据迁移”，选择来源和文件，再点击“读取来源”。预览会列出玩家数、记录数和可导入的项目。确认后点击对应的合并按钮；读取和导入均保留来源文件。

## 支持的文件

| 来源 | 可导入内容 |
| --- | --- |
| 原版导出的 XLSX | 抽卡记录；缺少玩家 ID 时需手动填写 |
| 原版 `sqlite.db` | 抽卡、游戏时长、挑战周期、签到历史、战斗日报、玩家资料和角色图鉴 |
| 原版 SQLite 账号 | 账号与绑定角色，独立于业务记录导入 |
| 原版 `settings.json` | 国服游戏路径与渠道、下载设置，以及可对应的窗口、启动、关闭和签到偏好 |

抽卡页面还支持导入原版 JSON 数组和 `pool.json`。`pool.json` 需要同时填写玩家 ID。

## 合并规则

可以分别合并抽卡、时长、挑战历史、签到历史、账号、设置与本地档案。重复记录会跳过；已明确保存的设置优先保留。

账号导入会保留已有会话和当前选择，同一账号的多个角色会合并。缺少可用登录凭据时，请在“库街区账号”重新登录。

挑战和签到历史按玩家归档。选择对应库街区角色后，在相关页面点击“查看本地历史”；原版挑战周期带有“原版导入”标识。

导入前可先备份助手的 `data/`。导入完成后，请核对玩家、记录数量和游戏路径，避免选择了其他安装目录的数据。
