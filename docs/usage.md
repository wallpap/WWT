# 使用指南

## 启动游戏和查看时长

在“启动器”点击“选择游戏”，选择游戏主程序，再选择资源档位。路径与档位会自动保存。点击“启动游戏”后，助手会记录本次游玩时长；计时期间请保持助手运行。

游戏时长可按玩家和日期筛选，查看今日、本周、本月及累计时长。历史日志也可用于补充记录。

“截图与资料”可以浏览当前游戏安装中的截图、打开原图或截图目录，也提供 Wiki 和地图入口。

## 抽卡记录

粘贴游戏内抽卡记录的完整 HTTPS 链接，或选择 `Client.log` 提取链接，再开始查询。查询会依次读取国服卡池，显示进度，并与本地记录合并。链接包含查询凭据，请勿分享。

也可以导入原版 XLSX、JSON 数组或 `pool.json`。文件缺少玩家 ID 时，需要手动填写。相同记录重复导入会跳过，文件中同秒出现的多次相同抽取会保留。

选择玩家与卡池后可查看统计，筛选结果可导出为 JSON 或 XLSX。五星历史按完整本地记录计算保底间隔；首条五星之前可能缺少记录，平均间隔使用后续完整区间。

## 库街区账号

在“库街区账号”填写手机号，点击“滑块验证并发送短信”，在浏览器完成验证后返回助手填写短信验证码。登录后选择绑定的游戏角色。

已有配套凭据时，也可展开“Token 与 Did 登录”进行验证。最多保存 9 个账号；同一账号的多个绑定角色可在页面切换。

账号会话保存在本机。更换电脑或 Windows 用户后需要重新登录，详见[数据与备份](data-storage.md)。

## 每日数据和签到

“每日数据”显示体力、每日活跃、电台、周常等信息。“刷新查询”重新读取数据，“同步游戏数据”请求官方同步后再查询。

“库街区签到”显示今日状态、本月奖励与历史。点击“为当前角色签到”执行签到，也可先查看全部账号角色，再批量签到。

启用自动签到后，助手会在启动时及北京时间每日 00:05 执行，休眠恢复后补执行。自动签到需要助手保持运行。若签到请求结果不明确，先刷新状态再决定是否重试。

“查看本地历史”可离线读取记录；返回今日签到操作前，请刷新状态。

## 角色、挑战和资源简报

“角色数据”展示共鸣者的属性、武器、声骸、共鸣链和技能。选择共鸣者查看详情；“查看本地缓存”可读取已保存的数据。未查询过的详情需要联网获取。

“挑战历史”分别展示逆境深塔、冥歌海墟和终焉矩阵。深塔按左、中、右塔区排列，海墟按难度排列，矩阵按模式排列。各列下方展示本期楼层、关卡或队伍。每个挑战可独立选择历史周期，周期截止时间与记录来源显示在分区上方。

“资源简报”按周、月或版本展示星声、贝币和来源明细。“读取历史”查看已保存周期，“补齐本类历史周期”获取缺少的周期；中途失败后可再次执行。

## 养成计算

选择角色或武器，填写当前等级和目标等级。默认目标为角色、武器 90 级、五项技能 10 级，并勾选进阶节点。

“同步当前角色练度”会填入所选角色的等级和技能等级，排除已解锁节点。可继续调整目标，再计算材料。

- “计算角色材料”和“计算武器材料”分别显示对应结果。
- “计算角色＋武器合计材料”将当前角色与武器的需求相加，同种材料合并数量。
- “保存角色目标”和“保存武器目标”将目标保存在当前玩家名下，可编辑、移除或批量计算。

结果分为全部需求、缺少材料和可合成关联材料，大屏并排显示。角色与武器合计中的缺少材料、可合成材料分别取两次结果之和。

## 兑换码和本地档案

“兑换码”读取 game-cal 提供的国服前瞻兑换码，可复制并查看截止时间。勾选“显示已失效兑换码”查看历史条目。兑换在游戏内完成；断网时可查看已保存的列表。

“本地档案”可按玩家和日期查看战斗日报、玩家资料与角色图鉴，也可扫描游戏战斗日志补充本地记录。

## 应用设置

可选择跟随系统、浅色或深色主题，并设置界面缩放、窗口尺寸、启动页、关闭行为和全局显示快捷键。主题选择会即时预览，点击“保存设置”后保留。

可设置游戏启动后隐藏助手、游戏结束后退出，以及手动打开助手时自动启动游戏。便携版支持当前 Windows 用户登录时启动与静默启动。关闭到托盘后，可通过托盘菜单恢复窗口或退出。

如需检查应用更新，在设置中填写本项目的 GitHub 仓库或 HTTPS 更新清单地址。发现新版本后依次选择“下载并校验”和“安装并重启”。升级前建议备份 `data/`，操作见[数据与备份](data-storage.md)。
